# Synapsis · Observatorio matemático

Synapsis es una calculadora de álgebra lineal y métodos numéricos para escritorio. Abrí [la guía de la aplicación](Synapsis/README.md) para instalarla y conocer sus módulos.

En Windows, ejecutá [Abrir-Synapsis.cmd](Synapsis/Abrir-Synapsis.cmd) desde la carpeta Synapsis. El proyecto histórico del repositorio se puede consultar en [la edición anterior](https://github.com/Rolando8-03/NexoLineal/tree/90fff924c0831f3b7cb1c5427be423a2a7177d93).
